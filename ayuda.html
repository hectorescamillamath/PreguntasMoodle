La idea

En lugar de escribir una pregunta, escribes una plantilla con variables. Por ejemplo: «Calcule {a} + {b}», donde a y b son números al azar. La respuesta también es una fórmula: a + b.

El generador crea muchas variantes (Calcule 3 + 7, Calcule 5 + 2…) con su respuesta correcta y las exporta a Moodle. Allí, con una pregunta aleatoria, cada estudiante recibe una variante distinta, lo que dificulta copiar. También puedes imprimir varias versiones (A, B, C…) con su clave.

Todo funciona en tu navegador: tus preguntas no se envían a ningún servidor. Se guardan automáticamente en este navegador; usa 💾 Guardar para tener una copia en un archivo.

Primera pregunta en 3 minutos

  1. Pulsa ＋ Nueva ▾ › 🔢 Numérica.
  2. En Enunciado escribe: Un rectángulo mide {b} cm de base y {h} cm de altura. ¿Cuál es su área?
  3. En Variables aleatorias escribe:
    b = randint(3, 15)
h = randint(2, 10)
  4. En Respuesta correcta escribe b*h y en Unidad, cm².
  5. Mira la Vista previa a la derecha y pulsa 🎲 Otra variante para comprobar que todo tiene sentido.
  6. Pulsa ⬇ Exportar a Moodle.

Variables aleatorias

Una variable por línea, con el formato nombre = expresión. Cada línea puede usar las variables anteriores. Lo que va después de # es un comentario.

a = randint(2, 9)          # entero entre 2 y 9
r = randnz(-6, 6)          # entero entre -6 y 6, distinto de 0
p = randreal(0.1, 0.9, 2)  # decimal con 2 cifras
d = choice(5, 10, 15, 20)  # uno de la lista
nombre = choice("Ana", "Luis", "Sofía")
c = a*r                    # calculada con las anteriores

Condición (opcional): si los valores no la cumplen, se generan otros. Ejemplos: a != b, b^2 - 4*a*c >= 0, a*d % b == 0 (que la división sea exacta). Se combinan con and y or.

Consejo: para que las respuestas sean «bonitas», genera primero el resultado y construye los datos a partir de él. Por ejemplo, para que una ecuación tenga solución entera: r = randint(-8, 8), c = a*r + b, y pregunta por {a}x + {b} = {c}.

Las llaves que no corresponden a una variable se dejan tal cual, por eso puedes escribir LaTeX como \frac{1}{2} sin problema. Si una variable se llama igual que algo que escribes entre llaves en LaTeX (por ejemplo {x} con una variable x), se reemplazará por su valor.

Los números se escriben con coma decimal. Dentro de las fórmulas se usa {,} automáticamente para que LaTeX no deje un espacio después de la coma.

Recetas útiles

Ecuación cuadrática con raíces enteras

r1 = randint(-6, 6)
r2 = randint(-6, 6)
b = -(r1 + r2)
c = r1*r2

Enunciado: Halle la mayor raíz de \( x^{2} {=coefs(b)}x {+c} = 0 \). · Respuesta: max(r1, r2) · Condición: r1 != r2 and b != 0 and c != 0

Porcentaje con nombres y dinero

nombre = choice("Ana", "Luis", "Camila")
precio = randint(40, 180)*1000
d = choice(10, 15, 20, 25)

Enunciado: {nombre} paga un artículo de ${=miles(precio)} con {d} % de descuento. ¿Cuánto paga? · Respuesta: precio*(1 - d/100)

Derivada parcial

a = randint(2, 6)
b = randint(1, 5)
x0 = randint(-2, 3)
y0 = randint(-2, 3)

Enunciado: Si \( f(x,y) = {a}x^{2}y + {=coef(b)}y^{3} \), calcule \( f_x({x0}, {y0}) \). · Respuesta: 2*a*x0*y0

Distractores típicos en opción múltiple

Usa los errores frecuentes de los estudiantes: el signo contrario {=-r}, olvidar dividir {=c-b}, sumar en lugar de restar, etc.

Importar en Moodle

1. Importar el archivo

  1. En el generador, pulsa ⬇ Exportar a Moodle y descarga el archivo .xml.
  2. En tu curso de Moodle, entra a Banco de preguntas (en Moodle 4.x: menú Más › Banco de preguntas, o desde la configuración del curso).
  3. Elige Importar, marca el formato Moodle XML, arrastra el archivo y pulsa Importar.
  4. Moodle muestra las preguntas importadas; pulsa Continuar. Quedan organizadas en la categoría Nombre del banco › Categoría › Nombre de la pregunta.

2. Que cada estudiante reciba una variante distinta

  1. Crea o abre el Cuestionario y entra a Preguntas.
  2. Pulsa Agregar › una pregunta aleatoria.
  3. Elige la subcategoría de una plantilla (por ejemplo, Derivada en un punto) y la cantidad 1. Pulsa Agregar pregunta aleatoria.
  4. Repite para cada plantilla. Cada intento tomará una variante al azar de cada subcategoría.
Por eso la exportación crea, por defecto, una subcategoría para cada plantilla: así cada pregunta aleatoria escoge solo entre las variantes de esa plantilla, y todos los estudiantes reciben preguntas equivalentes.

Decimales y Moodle

En el archivo, las respuestas numéricas se guardan con punto decimal, que es lo que Moodle espera. El estudiante puede escribir su respuesta con coma o con punto, según el idioma de Moodle.

Examen impreso

Pulsa 🖨 Examen impreso, completa el encabezado y elige cuántas versiones quieres (A, B, C…). Cada versión usa valores distintos. Opcionalmente puedes cambiar el orden de las preguntas, barajar las opciones y añadir la clave de respuestas al final.

En la vista que aparece, pulsa Imprimir / Guardar como PDF. En el diálogo del navegador, elige «Guardar como PDF» para obtener el archivo, o tu impresora para imprimir directamente. Cada versión empieza en una hoja nueva.

Guardar y compartir

  • El banco se guarda solo en este navegador. Si cambias de equipo o borras el historial, se pierde.
  • 💾 Guardar descarga un archivo .json con todas las plantillas. Ábrelo con 📂 Abrir en cualquier equipo.
  • Puedes compartir ese archivo con colegas para que reutilicen y adapten tus preguntas.

Problemas frecuentes

«No se encontraron valores que cumplan la condición»

La condición es demasiado estricta para los rangos elegidos. Amplía los rangos o revisa la condición.

«Solo salen N variantes distintas»

Con esos rangos no hay más combinaciones distintas. Amplía los rangos, agrega otra variable o pide menos variantes.

Aparece «{a}» sin reemplazar

La variable no está definida (revisa mayúsculas y minúsculas: A y a son distintas).

Sale «+ 0» o «1x» en un polinomio

Usa {=coef(a)}x y {=coefs(b)}x, o agrega una condición como c != 0.

La respuesta numérica tiene muchos decimales

Pide al estudiante redondear (por ejemplo, a 2 decimales) y usa un margen de error de 0,01, o usa round(…, 2) en la respuesta.
